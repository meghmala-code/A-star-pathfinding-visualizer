# 🧩 A* Pathfinding Visualizer

An interactive visualization of the **A* (A-star)** shortest path algorithm built using **Python and Pygame**.  
Users can draw obstacles, set start and end points, and watch the algorithm find the optimal path in real time.

---

## 🚀 Features
- Visualizes the A* algorithm step by step  
- Click to add/remove walls or reset the grid  
- Adjustable grid size and speed  
- Highlights open/closed nodes and final path

---

## 🛠️ Technologies Used
- **Python**
- **Pygame**

---

## ▶️ How to Run

```bash
# Clone the repository
git clone https://github.com/meghmala-code/astar-visualizer.git

# Navigate to folder
cd astar-visualizer

# Install dependencies
pip install -r requirements.txt

# Run
python main.py
